# HT-087: Quick Wins (Auto-Layout, Markdown Notes, CSV, Quick-Links)

**Status:** Ready
**MoSCoW:** Must
**Kano:** Performance / Delighter — a collection of minor implementations that leverage existing libraries to deliver massive usability improvements.
**Phase:** 1 (Hometower)
**Size:** S

## Job-to-be-Done

As an IT Admin/Homelabber, I want my existing tools (Cytoscape, NiceGUI, Database) to be fully exploited so that I can automatically arrange messy diagrams, write rich documentation, export my inventory to Excel, and launch SSH/HTTP sessions directly from the UI without needing entirely new architectures.

## Context

We already have Cytoscape.js running on the canvas, NiceGUI powering the frontend, and a Postgres/SQLModel database tracking all device metadata. While evaluating "missing features," we identified four high-value capabilities that require almost zero new architectural plumbing:
1. **Magic Auto-Layout:** Cytoscape natively supports directed graph algorithms (like Breadth-First or Dagre).
2. **Markdown Device Notes:** NiceGUI natively supports `ui.markdown()`. 
3. **One-Click CSV Export:** Python natively powers CSV generation; NiceGUI natively handles `ui.download()`.
4. **Quick-Connect Protocol Links:** Device IPs can easily map to `ssh://` or `http://` clickable links.

## Acceptance Criteria

Feature: Magic Auto-Layout
  Scenario: Untangling a messy canvas
    Given the user is on the topology canvas
    When they click a new "Auto-Layout" action button in the top toolbar
    Then the canvas smoothly animates and rearranges all nodes using a structured algorithm (e.g., Breadthfirst or Dagre) to minimize edge crossings.
    And the new positions trigger the autosave mechanism so they persist.

Feature: Rich-Text Device Notes
  Scenario: Viewing markdown notes
    Given a user enters markdown syntax (e.g., `# Header`, `**bold**`, or ````code````) into a Device's Notes field
    When the device properties panel renders the notes
    Then the notes are rendered as styled HTML markdown, not plain text.
    And editing the notes switches to a raw text area (or a split-pane editor), saving the markdown string back to the DB.

Feature: One-Click CSV Export
  Scenario: Exporting the inventory table
    Given the user is on the `/inventory` page
    When they click an "Export CSV" button near the search bar
    Then their browser immediately downloads a file `hometower_inventory_export.csv`
    And the CSV contains all primary columns: Name, Status, Type, IP, MAC, Location, and Notes.

Feature: Quick-Connect Protocol Links
  Scenario: Launching sessions from the web mapping
    Given a device has an IP address (e.g., `192.168.1.50`)
    When the user views the Device Detail panel
    Then the IP address is accompanied by quick-action icon buttons representing standard protocols (e.g., a terminal icon for SSH, a globe icon for HTTP/HTTPS).
    And clicking SSH attempts to launch `ssh://192.168.1.50` (triggering the OS default terminal handler).
    And clicking HTTP securely routes to `http://192.168.1.50` in a new browser tab.

## Non-Goals (explicitly out of scope)

- Building a custom interactive WYSIWYG or Block editor for notes (Standard Markdown only).
- Creating custom Cytoscape layout algorithms from scratch. We will use the built-in `dagre`, `cose`, or `breadthfirst` layouts.
- Building scheduled automated exports. CSV generation is strictly triggered by manual user clicks.

## Business Invariants

- Markdown parsing must be sanitized (NiceGUI’s markdown component usually handles this) to prevent XSS execution if a malicious user saves `<script>` tags in the notes field.
- Generating the CSV export must respect the Role-Based Access Control (RBAC); readers can export, but they cannot inject malicious data into the CSV pipeline.

## UX Interaction Spec

- **Auto-Layout Button**: An icon button (e.g., `account_tree` or `magic_button`) grouped with the "Zoom to Fit" and "Minimap" canvas controls.
- **Notes Field**: In read-mode, display `ui.markdown()`. In edit-mode, use a standard `ui.textarea()` spanning 100% width, adding a visual hint: "Markdown supported."
- **Protocol Buttons**: Use small, dense, flat icon buttons: `ui.button(icon='terminal').props('dense flat size=sm')`.

## Notes for Architect / Engineer

- **Auto-Layout**: Cytoscape's `cy.layout({ name: 'breadthfirst', directed: true, animate: true, animationDuration: 500 }).run()` is the fastest path here.
- **Markdown Notes**: Replace the current label readout with `ui.markdown(device.notes)`. Ensure that links open in a new tab (`target="_blank"`).
- **CSV Export**: Create a backend utility `export_devices_to_csv()`, generate a string or `io.StringIO`, encode into UTF-8, and use `ui.download(raw_content.encode(), filename="inventory_YYYYMMDD.csv")`.
- **Protocol Links**: Use standard `ui.link()` components wrapped in buttons, ensuring `target="_blank"` for web protocols to prevent losing the Hometower session.
