# HT-088: Advanced Quick Wins (Dark Mode, PNG Export, CSV Import, Tree View)

**Status:** Cancelled
**MoSCoW:** Won't
**Kano:** Performance / Delighter
**Phase:** 1 (Hometower)
**Size:** S

## Job-to-be-Done

As an IT Admin, I want to further exploit built-in capabilities so that I can bulk-import devices, view my infrastructure as a folder tree, export diagram images for reports, and work without straining my eyes.

## Context

Following up on the first batch of existing-library quick wins, we have several native features in NiceGUI and Cytoscape that are practically "free" to implement and dramatically boost the "premium" feel. 
1. **Dark Mode:** NiceGUI has `ui.dark_mode()`.
2. **Canvas Image Export:** Cytoscape can instantly serialize the canvas to an image using `cy.png()`.
3. **CSV Bulk Import:** We built export; `ui.upload()` natively handles drag-and-drop file ingestion.
4. **Hierarchy Explorer:** NiceGUI provides `ui.tree()` to represent nested node data (perfect for a Location > Parent > Child view).

## Acceptance Criteria

Feature: Global Dark Mode Toggle
  Scenario: Toggling visual themes
    Given the user is on any Hometower screen
    When they click the theme toggle icon (sun/moon) in the main header
    Then NiceGUI's `ui.dark_mode().toggle()` is called
    And the app visually switches between light and dark palettes
    And the preference is persisted (via local storage or session cookie).

Feature: Diagram PNG Export
  Scenario: Capturing a snapshot for a report
    Given the user is viewing a populated topology canvas
    When they click the "Export PNG" action button in the canvas toolbar
    Then a Javascript command fires `cy.png({ bg: 'transparent', full: true })`
    And the browser downloads the high-resolution snapshot of the diagram.

Feature: Bulk CSV Import
  Scenario: Bootstrapping a new workspace
    Given the user is on the empty `/inventory` view
    When they drag and drop a properly formatted `.csv` file into the "Bulk Import" dropzone
    Then the backend parses the CSV rows and bulk-inserts them into the PostgreSQL devices table
    And the table refreshes automatically showing all imported devices.

Feature: Hierarchy Explorer (Tree View)
  Scenario: Browsing strict parent-child relationships
    Given the user wants to browse devices strictly by container rather than a flat table
    When they toggle the "Tree View" tab in the inventory panel
    Then NiceGUI's `ui.tree()` component renders the data as expandable folders (Location -> Enclosure -> Device)
    And clicking a tree node opens that device's details panel.

## Non-Goals (explicitly out of scope)

- High-resolution SVG export (PNG only, as standard in Cytoscape).
- Complex CSV mapping wizards. The CSV headers must exactly match our expected schema; we will reject cleanly if it fails, rather than offering a column-mapping UI.

## Business Invariants

- Bulk Import MUST run inside a single database transaction. If row 50 fails validation, the entire bulk import rolls back. We do not support partial imports.
- Imported data must still pass through all Pydantic validators and RBAC checks (must have Contributor/Admin role).

## UX Interaction Spec

- **Dark Mode**: Top-right corner of the persistent app-header. `icon='dark_mode'` switching to `light_mode`.
- **CSV Dropzone**: Rendered inline as an alternate empty-state for the Inventory table if the table has 0 rows, or hidden behind an "Import" button.
- **Tree View**: A standard dual-pane view constraint. Left side = `ui.tree()`, Right side = Selected Node details.

## Notes for Architect / Engineer

- **Dark Mode**: Be sure that custom Tailwind classes used in HT-080 also correctly specify `dark:...` variants so they don't break when Native dark mode enables.
- **CSV Import**: Use FastAPI/NiceGUI's `ui.upload(on_upload=...)` which handles the async file read securely.
- **Tree Rendering**: The backend will need a quick recursive function to map flat DB devices (with `parent_id` and `location_id`) into the hierarchical `[{"id": 1, "label": "Site A", "children": [...]}]` dict structure expected by `ui.tree()`.
