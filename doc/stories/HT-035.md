# HT-035: About / System Info Page

**Status:** Ready
**MoSCoW:** Should
**Kano:** Performance — homelabbers check system info pages compulsively. "What version am I on?" is the first debug question. This is visible in every peer tool (Portainer, Unraid, TrueNAS, Netbox).
**Phase:** 1 (Hometower)
**Size:** XS (half day)

## Job-to-be-Done
As a homelab owner, I want a system info page showing Hometower's version, database statistics, and instance summary so that I can quickly verify what's running, how large my inventory is, and whether an update is needed.

## Context
There is currently no "About" or system diagnostics page in Hometower. Users have no way to know the running version, database size, or aggregate statistics without querying the API directly or running SQL against the container.

This page lives under Settings in the navigation shell (HT-026).

## Acceptance Criteria
- Given I am authenticated, when I navigate to `/settings/about`, then I see a system info page
- Given the page loads, when I read the "Application" section, then I see: app name ("Hometower"), version (from `src/__version__.py` — same source as HT-034), Python version, and NiceGUI version
- Given the page loads, when I read the "Database" section, then I see: PostgreSQL version (from `SELECT version()`), database size (from `pg_database_size()`), and connection pool status (active/idle connections)
- Given the page loads, when I read the "Inventory Summary" section, then I see counts: total devices, connections, locations, tags, custom fields, saved diagrams, and users
- Given I am a Reader or Contributor, when I access the page, then I see all information except user count (Admin only)
- Given the page loads, when I read the "Runtime" section, then I see: server uptime (from HT-034's uptime tracking), and the current server time (UTC)

## Non-Goals (explicitly out of scope)
- Update check against a remote server or GitHub releases
- Log viewer or log download
- Configuration editor (viewing/editing .env values)
- Performance metrics or request history
- License information

## Open Questions
None.

## Notes for Architect / Engineer
- **Page**: `src/ui/pages/settings_about.py` registered at `/settings/about`. Import in `src/main.py`.
- **Sidebar**: Add "About" under the Settings group in the navigation shell (HT-026), below "Users". Available to all authenticated roles.
- **Data source**: Call `GET /api/health` for version + uptime. Add a new `GET /api/system/stats` endpoint returning inventory counts and DB diagnostics (Admin-only for DB details, counts available to all).
- **DB queries**: `SELECT version()`, `SELECT pg_database_size(current_database())`, count queries on each table. Run in a single read transaction.
