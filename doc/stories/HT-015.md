# HT-015: Dark Mode Toggle

**Status:** Superseded by HT-027
**MoSCoW:** Could
**Kano:** Delighter — homelabbers live in terminals and dark UIs. Dark mode signals "this tool is for us."
**Phase:** 1 (Hometower)
**Size:** XS (half day)

## Job-to-be-Done
As a homelab owner who works at night, I want to toggle dark mode so that Hometower doesn't blind me at 2 AM when I'm debugging a network issue.

## Context
NiceGUI has built-in dark mode support via `ui.dark_mode()`. Cytoscape.js nodes and edges need style overrides for dark backgrounds. The map view (HT-008) already plans to switch tile providers for dark mode (CartoDB dark tiles). This story wires a persistent toggle.

## Acceptance Criteria
- Given I am authenticated, when I click the dark mode toggle in the top-right navbar, then the entire UI switches to dark theme (background, text, cards, inputs, canvas)
- Given I switch to dark mode, when I reload the page, then dark mode persists (stored in a cookie or localStorage)
- Given I am in dark mode, when I view the topology canvas, then node labels, edge labels, and selection highlights are adjusted for readability on a dark background
- Given I am in dark mode, when I view the map (HT-008), then the dark tile variant loads
- Given I switch modes, when the transition happens, then there is no flash of the opposite theme (no FOUC)
- Given I am a Reader, when I toggle dark mode, then it works (preference is per-user, not a system setting)

## Non-Goals (explicitly out of scope)
- System-preference auto-detection (`prefers-color-scheme`) — explicit toggle only in v1
- Per-page or per-component theme overrides
- Custom colour theme beyond light/dark
- Theming of exported PNG/SVG (exports always use white background)

## Open Questions
None — NiceGUI's `ui.dark_mode()` handles the heavy lifting.

## Notes for Architect / Engineer
- Toggle: `ui.dark_mode().toggle()` in response to a button click in the navbar component
- Persistence: set a `dark_mode=true/false` cookie; read it on page load and apply before first render
- Cytoscape styles: define a `DARK_STYLES` variant in `src/ui/design/tokens.py` and apply via `cy.style().fromJson(styles).update()` when mode changes
- Map tiles: HT-008 already specifies CartoDB dark tiles — the map component should check the cookie and pick the tile URL accordingly
- No backend endpoint — this is a client-side preference
- Files touched: navbar component (add toggle button), `src/ui/design/tokens.py` (dark palette), `src/ui/components/canvas.py` (dark Cytoscape styles)
