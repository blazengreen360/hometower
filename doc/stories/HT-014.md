# HT-014: Export Canvas to PNG/SVG

**Status:** Ready
**MoSCoW:** Could
**Kano:** Delighter — "I can screenshot my topology and paste it into my wiki" makes users feel capable and proud of their setup.
**Phase:** 1 (Hometower)
**Size:** S (1 day)

## Job-to-be-Done
As a homelab owner, I want to export my View Designer canvas as a PNG or SVG image so that I can embed it in documentation, share it in a Discord channel, or print it.

## Context
Cytoscape.js natively supports `cy.png()` and `cy.svg()` for client-side image export. This story wires those to a UI button. No backend involvement — the image is generated entirely in the browser and downloaded via a blob URL.

## Acceptance Criteria
- Given I am on the View Designer canvas, when I click the "Export" dropdown and select "PNG", then a PNG image of the current canvas view downloads with filename `hometower-topology-{YYYY-MM-DD}.png`
- Given I select "SVG", then an SVG file downloads with the same naming convention
- Given the canvas is zoomed/panned, when I export, then the image captures the **full graph** (all nodes and edges), not just the visible viewport — uses `cy.png({full: true})`
- Given the canvas has a transparent background, when I export PNG, then the background is white (not transparent) for readability
- Given the canvas has 100+ nodes, when the PNG export runs, then it completes without freezing the UI (max 2 seconds)
- Given I am a Reader, when I click export, then it works (read-only action, all roles allowed)
- Given the canvas is empty (zero nodes), when I click export, then the button is disabled with tooltip: "Add devices to the canvas first"

## Non-Goals (explicitly out of scope)
- PDF export
- Server-side rendering (headless Cytoscape)
- Custom resolution or DPI settings
- Watermarks or branding on the exported image
- Export of the map view (Leaflet) — only the Cytoscape canvas

## Open Questions
None — Cytoscape.js export API is well-documented and this is purely client-side.

## Notes for Architect / Engineer
- Pure JavaScript: `cy.png({full: true, bg: '#ffffff', scale: 2})` for retina-quality PNG; `cy.svg({full: true})` for SVG
- Download trigger: create a temporary `<a>` element with `href=blobURL` and `download=filename`, click it programmatically
- UI: add an "Export" split button or dropdown to the View Designer toolbar (next to Save Layout); two options: PNG, SVG
- Disable when `cy.nodes().length === 0`
- No new backend endpoints, no new Python files — this is entirely in `src/ui/components/canvas.py` or a small `src/ui/components/canvas_export.py`
- File size budget: ~30 lines of JavaScript injected via `ui.run_javascript()`
