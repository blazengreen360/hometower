# HT-003: Basic Topology Canvas with Drag-Drop

**Status:** Ready
**MoSCoW:** Must
**Phase:** 1 (Hometower)
**Size:** L (5-7 days)

## Job-to-be-Done
As a homelab owner, I want to drag devices onto a canvas and arrange them spatially so that I can visualize my infrastructure topology.

## Context
This is THE core differentiator of Hometower. The topology canvas is embedded Cytoscape.js inside a NiceGUI page. Users drag device types from a palette onto the canvas, which creates both a visual node AND a database record. Moving a node updates its position in the saved layout.

This story covers rendering, drag-drop, and basic interaction. Connections between devices are covered in HT-004.

## Acceptance Criteria
- Given I am on the topology page, when the page loads, then I see a Cytoscape.js canvas filling the viewport with pan and zoom enabled
- Given I see a device palette sidebar, when I drag a "Server" icon onto the canvas, then a new device node appears at the drop location and a `POST /api/devices` call creates the record
- Given a device node exists on the canvas, when I drag it to a new position, then the node moves and a `PATCH /api/devices/{id}` call updates its `x` and `y` coordinates in the database
- Given I have multiple devices on the canvas, when I save the layout, then a `POST /api/diagrams` call saves the current Cytoscape.js node positions and edge routing
- Given I reload the page, when the canvas renders, then all devices appear in their previously saved positions
- Given I click a node, when it is selected, then the node is highlighted and a detail panel opens on the right showing device info (name, type, IP, MAC, notes)
- Given I right-click a node, when the context menu appears, then I see options: "Edit", "Delete", "Duplicate"

## Non-Goals (explicitly out of scope)
- Drawing connections (HT-004)
- Auto-layout algorithms (not in v1)
- Grouping/clustering nodes (not in v1)
- Minimap or overview panel (not in v1)
- Undo/redo (HT-016 covers keyboard shortcuts separately)
- Node icons or custom styling (use basic shapes for v1)

## Notes for Architect / Engineer
- Cytoscape.js embedded via `ui.add_body_html()` in `src/ui/pages/topology.py`
- Device palette rendered as NiceGUI sidebar with draggable icons
- Cytoscape node data structure: `{id: device_id, label: device_name, type: device_type, position: {x, y}}`
- Drag-drop from palette triggers JavaScript callback → `ui.run_javascript()` → Python handler → FastAPI `POST /api/devices`
- Node position updates on drag-end event → debounced `PATCH /api/devices/{id}` (max 1 request per second)
- Layout persistence: store Cytoscape.js JSON in `diagram_layouts` table (one active layout per user)
- Use Cytoscape's `cose` layout as default for initial placement if no position is set
- Pan/zoom state NOT persisted (resets to fit-to-viewport on load)
- Device palette device types: Server (rectangle), Switch (diamond), Router (triangle), NAS (hexagon), VM (circle), Container (rounded rectangle), VLAN (ellipse)
